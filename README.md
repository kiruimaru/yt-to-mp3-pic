# YouTube → MP3

Скачивает аудио из видео на YouTube, конвертирует в MP3 и сохраняет обложку.
Обложка и метаданные (название, автор) встраиваются прямо в MP3.
Интерфейс — в тёмной теме.

## Что внутри

- `app.py` — графическое приложение (окно с полем для ссылки, выбором папки и битрейта).
- `youtube_to_mp3.py` — версия для командной строки.
- `Запустить.bat` — запуск приложения в один клик (Windows).

## Требования

Нужен только **Python 3.8+**. Всё остальное ставится само.

Пакеты `yt-dlp` и `imageio-ffmpeg` (в нём уже встроен ffmpeg) доустанавливаются
автоматически при первом запуске — вручную ничего докачивать не нужно и
настраивать PATH тоже не требуется.

## Запуск

Windows — двойной клик по `Запустить.bat`.

Или из терминала:
```
python app.py
```

Версия для командной строки:
```
python youtube_to_mp3.py "https://youtu.be/XXXX" -o ./музыка -q 320
```

Если хотите поставить зависимости заранее:
```
pip install -r requirements.txt
```
