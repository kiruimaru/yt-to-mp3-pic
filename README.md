# YouTube → MP3

Скачивает аудио с **YouTube** и **SoundCloud**, конвертирует в MP3 и сохраняет обложку.
Обложка и метаданные (название, автор) встраиваются прямо в MP3.
Интерфейс — в тёмной теме, с переключателем языка RU / EN и выбором источника.

## Для обычного пользователя (без Python)

Нужен готовый `.exe` — он не требует ни Python, ни ffmpeg, ничего.
Просто скачайте `YouTube-to-MP3.exe` (из раздела Releases на GitHub) и
запустите двойным кликом. Всё уже внутри.

## Для разработчика

### Что внутри

- `app.py` — графическое приложение (тёмная тема, поле URL, выбор папки и битрейта).
- `youtube_to_mp3.py` — версия для командной строки.
- `Запустить.bat` — запуск из исходников в один клик (Windows).
- `Собрать-EXE.bat` — сборка автономного `.exe` в один клик (Windows).

### Запуск из исходников

Нужен только **Python 3.8+**. Зависимости (`yt-dlp`, `imageio-ffmpeg` со
встроенным ffmpeg) ставятся автоматически при первом запуске.

Windows — двойной клик по `Запустить.bat`. Или из терминала:
```
python app.py
```

Версия для командной строки:
```
python youtube_to_mp3.py "https://youtu.be/XXXX" -o ./музыка -q 320
```

### Сборка .exe для друзей (без Python)

Двойной клик по `Собрать-EXE.bat` — он сам поставит PyInstaller и соберёт
единый файл со встроенным Python и ffmpeg. Готовый `YouTube-to-MP3.exe`
появится в папке `dist`. Этот один файл можно отправлять кому угодно.

Файл получится крупным (~80–100 МБ), потому что внутри лежит ffmpeg.
Первый запуск чуть медленный — exe распаковывается во временную папку.
