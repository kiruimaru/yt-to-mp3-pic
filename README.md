# YouTube → MP3

Скачивает аудио из видео на YouTube, конвертирует в MP3 и сохраняет обложку.
Обложка и метаданные (название, автор) встраиваются прямо в MP3.

## Что внутри

- `app.py` — графическое приложение (окно с полем для ссылки, выбором папки и битрейта).
- `youtube_to_mp3.py` — версия для командной строки.

## Требования

1. **Python 3.8+**
2. **yt-dlp** — установка:
   ```
   pip install -r requirements.txt
   ```
3. **ffmpeg** — нужен для конвертации в MP3. Устанавливается автоматически
   вместе с зависимостями (пакет `imageio-ffmpeg`), ручная настройка PATH не нужна.

   Если хотите поставить системный ffmpeg вручную:
   - Windows: скачайте с https://www.gyan.dev/ffmpeg/builds/ и добавьте в PATH
   - macOS: `brew install ffmpeg`
   - Linux: `sudo apt install ffmpeg`

## Запуск

Графическое приложение:
```
python app.py
```

Командная строка:
```
python youtube_to_mp3.py "https://youtu.be/XXXX" -o ./музыка -q 320
```

## Замечание

Скачивайте только тот контент, на который у вас есть права или разрешение автора.
